# Palo Alto Career Analytics 📊

## Project Overview

Palo Alto Career Analytics is an interactive data analytics application designed to analyze employee career progression, promotion gaps, and retention patterns.

The project uses Python, Power BI, and Streamlit to transform employee data into meaningful insights and interactive dashboards.

## Objectives

- Analyze employee demographics and workforce distribution
- Understand career progression patterns
- Identify promotion gaps
- Analyze employee attrition and retention
- Explore employee-level information using interactive filters
- Present insights through interactive dashboards

## Dataset

The analysis is based on an employee dataset containing 1,470 employee records and multiple workforce-related attributes.

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Streamlit
- Power BI
- GitHub

## Streamlit Dashboard

The application contains:

### Executive Dashboard
Provides key workforce KPIs including:
- Total Employees
- Average Age
- Average Experience
- Attrition Rate
- Department Distribution
- Employee Attrition
- Job Level Distribution

### Career Clusters
Groups employees according to experience levels:
- Early Career
- Mid Career
- Experienced
- Senior Career

### Promotion Gap
Analyzes years since the employee's last promotion and identifies longer promotion-gap groups.

### Retention Opportunities
Examines employee attrition across departments, job roles, and overtime status.

### Employee Explorer
Allows users to interactively filter employees by:
- Department
- Gender
- Job Level
- Attrition
- Years at Company
