# 📊 Palo Alto Career Analytics

## Project Overview

Palo Alto Career Analytics is an interactive data analytics project designed to analyze employee career progression, promotion gaps, workforce distribution, and retention patterns.

The project uses Python, Power BI, and Streamlit to transform employee data into meaningful insights and interactive dashboards.

---

## 🎯 Objectives

- Analyze employee demographics and workforce distribution
- Understand employee career progression patterns
- Identify promotion gaps
- Analyze employee attrition and retention
- Explore employee-level information using interactive filters
- Present insights through interactive dashboards

---

## 📂 Dataset

The analysis is based on an employee dataset containing **1,470 employee records** and **31 workforce-related attributes**.

The dataset includes information related to:

- Employee demographics
- Department
- Job role
- Job level
- Years at company
- Total working years
- Years since last promotion
- Job satisfaction
- Overtime
- Attrition
- Salary-related information
- Work and career attributes

# 🐍 Python Analysis

The Python analysis was performed using Jupyter Notebook.

### Analysis includes:

- Dataset loading and exploration
- Data quality checking
- Employee demographic analysis
- Career progression analysis
- Promotion gap analysis
- Attrition and retention analysis
- Career cluster analysis
- Data visualization
- Employee-level insights

### Key Analysis Areas

#### Career Progression

Employees were grouped into career stages based on their years of experience:

- Early Career
- Mid Career
- Experienced
- Senior Career

#### Promotion Gap

Employees were analyzed according to the number of years since their last promotion.

Promotion gap categories include:

- 0–2 years
- 3–5 years
- 6–10 years
- 10+ years

#### Retention Analysis

Employee attrition was analyzed across:

- Departments
- Job roles
- Overtime status
- Employee characteristics

# 🚀 Streamlit Dashboard

The Streamlit application provides an interactive web-based analytics dashboard.

## Executive Dashboard

Provides key workforce KPIs including:

- Total Employees
- Average Age
- Average Experience
- Attrition Rate
- Department Distribution
- Employee Attrition
- Job Level Distribution

## Career Clusters

Analyzes employees according to career experience and groups them into:

- Early Career
- Mid Career
- Experienced
- Senior Career

## Promotion Gap

Analyzes the time since employees received their last promotion.

The dashboard provides:

- Promotion gap categories
- Average years since promotion
- Employees with longer promotion gaps
- Department-wise promotion gap analysis

## Retention Opportunities

Examines employee attrition across:

- Departments
- Job roles
- Overtime status

## Employee Explorer

Allows users to interactively filter employees by:

- Department
- Gender
- Job Level
- Attrition
- Years at Company
